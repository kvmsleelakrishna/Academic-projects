## 1. HandSpeak – A Novel Sign Language Translator

### Domain
Embedded Systems | Assistive Technology | Gesture Recognition

### Overview
HandSpeak is a low-cost wearable sign language translation system designed to interpret predefined hand gestures and convert them into readable text in real time.

### Technologies & Components
- Arduino Mega 2560
- Five Flex Sensors
- I2C 16×2 LCD Display
- Arduino IDE
- Analog sensor interfacing
- Threshold-based gesture recognition

### Working
Flex sensors mounted on a wearable glove detect finger bending and generate corresponding analog signals. The Arduino Mega 2560 processes the sensor values and identifies predefined gestures using threshold values. The recognized output is displayed on a 16×2 LCD through I2C communication.

### Results
The prototype was tested with six gesture scenarios, including Food, Wash Room, Rest Room, Class Room and Friendship. The reported success rates for the tested scenarios ranged from 90% to 99%.

## 2. Numerical Investigation and Optimization of Perovskite Solar Cells

### Domain
Semiconductor Devices | Solar Photovoltaics | Numerical Simulation

### Overview
This project investigates and optimizes the performance of perovskite solar cells using numerical device simulation. Different perovskite absorber materials and device parameters were studied to evaluate their influence on photovoltaic performance.

### Technologies & Tools
- SCAPS-1D
- Semiconductor device modelling
- Perovskite solar cell simulation
- Photovoltaic parameter analysis
- Numerical optimization

### Device Structures Studied
- FTO/PCBM/CH₃NH₃PbI₃/CuSCN/Au
- FTO/PCBM/FA-Cs-Sn-Pb-I/CuSCN/Au

### Key Parameters
The study evaluates:
- Open-circuit voltage (Voc)
- Short-circuit current density (Jsc)
- Fill Factor (FF)
- Power Conversion Efficiency (PCE)
- Absorber thickness
- Operating temperature

### Key Outcome
The simulated FA-Cs-Sn-Pb-I based device demonstrated a maximum theoretical power conversion efficiency of 32.77% under the defined simulation conditions.
